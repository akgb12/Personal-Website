# Experience Content Notes

The Experience section uses **no bullet lists**.

Recommended visible fields for each active scene:

- role
- organization
- `MMM YYYY – MMM YYYY` or `MMM YYYY – Present`
- location
- logo/image
- optional single-sentence context

Canonical experience data is in:
`_onboarding/data/experience.json`
